# Phishing Website Detection Using AI/ML

## About the Project
This project detects potentially phishing websites using Machine Learning. Users can enter a website URL to receive a prediction about whether it is phishing or legitimate.

## Features
- URL-based phishing detection
- Machine Learning model
- Simple Streamlit user interface
- Prediction results with probability scores

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## How to Run Locally

1. Install Python.
2. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   streamlit run app.py
   ```

## Project Files
- `app.py` — Main application
- `url_model.pkl` — Trained Machine Learning model
- `requirements.txt` — Required Python packages

## Disclaimer
This project is for educational purposes. Predictions are not a guarantee that a website is safe or malicious.
